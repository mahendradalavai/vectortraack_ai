# VectorTrack AI

This repository contains a YOLO-style object detection and tracking project.

## Project Structure

- `dataset/` – training, validation, and test datasets
- `models/` – saved model artifacts
- `videos/` – input video sources
- `output/` – inference outputs
- `runs/` – training and detection run artifacts

## Usage

1. Install dependencies from `requirements.txt`
2. Prepare the dataset in `dataset/`
3. Run training with `train.py`
4. Run inference with `detect.py`
